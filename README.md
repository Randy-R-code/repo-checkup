# RepoCheckup

> Give your JavaScript or TypeScript repository a quick checkup.

RepoCheckup is a zero-config CLI that checks JavaScript and TypeScript repositories for configuration, tooling, testing, CI, and project health.

## Usage

> RepoCheckup is currently under development.

The intended usage is:

```bash
npx repo-checkup
```

## Development

```bash
pnpm install
pnpm dev
pnpm typecheck
pnpm test
pnpm build
```
